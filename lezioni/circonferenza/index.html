La Circonferenza nella Geometria Analitica: Luoghi ed Equazioni

01 — Dal Luogo Geometrico all'Algebra: Introduzione

Nel piano cartesiano abbiamo imparato a rappresentare le rette tramite equazioni di primo grado. Tuttavia, molte forme della natura, della fisica e della tecnologia non seguono percorsi rettilinei, ma descrivono curve e traiettorie piane di secondo grado: le coniche.

La più semplice e perfetta tra le coniche è la circonferenza. Se vogliamo modellizzare l'orbita circolare di un satellite attorno a un punto centrale o l'area di copertura di un'antenna trasmettitrice, abbiamo bisogno di tradurre la proprietà geometrica di equidistanza in un'equazione algebrica tra le coordinate x e y.

📐 Applicazioni della Circonferenza
La circonferenza si incontra costantemente nella modellizzazione e nella fisica:
  • Geolocalizzazione (GPS): Intersezione di circonferenze di raggio noto dai satelliti per determinare la posizione.
  • Moto Circolare Uniforme: La traiettoria di un punto materiale ad una distanza fissa r dal centro di rotazione.
  • Ingegneria e Architettura: Archi a tutto sesto, ruote dentate e strutture portanti a sezione circolare.
02 — Cos'è la Circonferenza: Definizione Geometrica
💡 Definizione Formale
La circonferenza è il luogo geometrico dei punti del piano cartesiano che hanno distanza costante, detta raggio (r > 0), da un punto fisso detto centro C(x₀, y₀).

Un generico punto P(x, y) appartiene alla circonferenza se e solo se la sua distanza dal centro C è pari a r, ossia d(P, C) = r.

Deduzione dell'Equazione con il Teorema di Pitagora

Utilizzando la formula della distanza tra due punti nel piano cartesiano:

1️⃣ Distanza tra P(x, y) e C(x₀, y₀): √[(x - x₀)² + (y - y₀)²] = r
2️⃣ Elevando al quadrato entrambi i membri: (x - x₀)² + (y - y₀)² = r²

Questa è l'equazione della circonferenza con centro C(x₀, y₀) e raggio r.

03 — L'Equazione Canonica o Generale

Sviluppando i quadrati dei binomi nell'equazione (x - x₀)² + (y - y₀)² = r², otteniamo:

x² - 2x₀x + x₀² + y² - 2y₀y + y₀² - r² = 0

Ponendo: a = -2x₀, b = -2y₀ e c = x₀² + y₀² - r², arriviamo alla forma canonica della circonferenza.

🧹 Forma Canonica (o Cartesiana Generale)
L'equazione generale di una circonferenza è:
x² + y² + ax + by + c = 0
Caratteristiche fondamentali:
  • È un'equazione di 2° grado nelle variabili x e y.
  • I coefficienti di x² e y² sono uguali (e riducibili a 1).
  • Non compare il termine misto xy (coefficiente del termine xy pari a 0).
04 — Coordinate del Centro e Misura del Raggio

Data l'equazione in forma canonica x² + y² + ax + by + c = 0, possiamo ricavare le proprietà geometriche fondamentali tramite le seguenti relazioni:

📊 Formule Fondamentali
  • Coordinate del Centro C: C(x₀, y₀) = C(-a/2, -b/2)
  • Lunghezza del Raggio r: r = √[(a/2)² + (b/2)² - c] = √(x₀² + y₀² - c)
⚠️ Condizione di Esistenza (Circonferenza Reale)
Affinché l'equazione rappresenti una circonferenza reale con raggio non nullo, il radicando deve essere strettamente positivo:
(a/2)² + (b/2)² - c > 0
• Se il radicando è uguale a 0, la circonferenza degenera in un singolo punto (il centro).
• Se il radicando è minore di 0, la circonferenza si dice non reale (nessun punto del piano la soddisfa).
📝 Esempio Guidato
Determina centro e raggio della circonferenza: x² + y² - 6x + 4y - 12 = 0
• Coefficienti: a = -6, b = 4, c = -12
• Centro C: x₀ = -(-6)/2 = 3, y₀ = -(4)/2 = -2 → C(3, -2)
• Raggio r: r = √(3² + (-2)² - (-12)) = √(9 + 4 + 12) = √25 = 5 → r = 5
05 — Casi Particolari dell'Equazione

Se uno o più coefficienti a, b, c sono nulli, la circonferenza assume posizioni particolari rispetto agli assi cartesiani:

Condizione Equazione Proprietà Geometrica
a = 0x² + y² + by + c = 0Centro sull'asse y: C(0, -b/2)
b = 0x² + y² + ax + c = 0Centro sull'asse x: C(-a/2, 0)
c = 0x² + y² + ax + by = 0Passa per l'origine degli assi O(0, 0)
a = 0 e b = 0x² + y² + c = 0Centro nell'origine O(0, 0)
a = 0 e c = 0x² + y² + by = 0Centro sull'asse y e passa per l'origine
b = 0 e c = 0x² + y² + ax = 0Centro sull'asse x e passa per l'origine
06 — Posizioni Relative tra Retta e Circonferenza

Per studiare le intersezioni tra una retta s e una circonferenza γ, si considera il sistema formato dalle equazioni della retta e della circonferenza, ottenendo un'equazione risolvente di secondo grado con discriminante Δ.

Posizione Relativa Punti di Intersezione Condizione sul Discriminante (Δ) Condizione sulla Distanza d(C, r)
Secante2 punti distinti P₁, P₂Δ > 0d < r
Tangente2 punti reali e coincidenti TΔ = 0d = r
EsternaNessun punto realeΔ < 0d > r
💡 Metodo Alternativo Geometrico
Invece di calcolare il sistema e il discriminante Δ, si può confrontare la distanza d del centro C dalla retta s con la misura del raggio r usando la formula della distanza punto-retta:
d = |ax₀ + by₀ + c| / √(a² + b²).
07 — Rette Tangenti

Data una circonferenza e un punto P(xₚ, yₚ), il numero di rette tangenti condotte da P dipende dalla posizione di P rispetto alla circonferenza:

  • P è esterno: Esistono 2 rette tangenti.
  • P appartiene alla circonferenza: Esiste 1 sola retta tangente.
  • P è interno: Non esiste nessuna retta tangente reale.

Metodi per Trovare l'Equazione delle Tangenti

Metodo 1 (Geometria - Distanza centro-retta):
1. Scrivere il fascio di rette passanti per P:
y - yₚ = m(x - xₚ) → mx - y + (yₚ - m xₚ) = 0.

2. Imporre che la distanza del centro C dalla retta sia uguale al raggio: d(C, s) = r.
3. Risolvere l'equazione nell'incognita m.
Formula di Sdoppiamento (Se P appartiene alla circonferenza):
Se il punto P(x₀, y₀) appartiene alla circonferenza x² + y² + ax + by + c = 0, l'equazione della tangente in P si ottiene sostituendo:
x² → x₀x,    y² → y₀y,    x → (x + x₀)/2,    y → (y + y₀)/2
Equazione della tangente: x₀x + y₀y + a((x + x₀)/2) + b((y + y₀)/2) + c = 0
08 — Determinare l'Equazione di una Circonferenza

L'equazione canonica x² + y² + ax + by + c = 0 contiene 3 parametri indipendenti a, b, c. Pertanto, per individuare univocamente una circonferenza occorrono 3 condizioni indipendenti.

Esempi di Triple di Condizioni Sufficienti

  • Passaggio per 3 punti non allineati.
  • Coordinate del centro C(x₀, y₀) e misura del raggio r.
  • Coordinate del centro C e passaggio per un punto P.
  • Passaggio per 2 punti e centro appartenente a una retta data.
  • Passaggio per 2 punti e tangenza a una retta data.
09 — Guida all'Autocorrezione degli Errori Frequenti
⚠️ Errore 1: Calcolare il centro senza normalizzare i coefficienti di x² e y²
• Sbagliato: Data 2x² + 2y² - 8x + 4y - 6 = 0, dire che a = -8 e b = 4 → C(4, -2).
• Spiegazione: Prima di usare le formule di centro e raggio, occorre dividere tutta l'equazione per il coefficiente di x² e y² (in questo caso 2).
• Corretto: Dividendo per 2 si ottiene x² + y² - 4x + 2y - 3 = 0. Quindi a = -4, b = 2 → C(2, -1).
⚠️ Errore 2: Dimenticare il segno meno nelle coordinate del centro
• Sbagliato: Per la circonferenza x² + y² + 6x - 8y = 0, affermare che C(3, -4).
• Spiegazione: Ricorda la formula x₀ = -a/2 e y₀ = -b/2. I segni vanno invertiti!
• Corretto: x₀ = -6/2 = -3 e y₀ = -(-8)/2 = 4 → C(-3, 4).
⚠️ Errore 3: Considerare reale una circonferenza con radicando negativo
• Sbagliato: Dire che x² + y² - 2x - 2y + 10 = 0 è una circonferenza di raggio r = √(-8).
• Spiegazione: La radice di un numero negativo non esiste nei numeri reali. L'equazione non rappresenta alcun punto reale.
• Corretto: L'equazione non rappresenta una circonferenza reale (raggio non reale).
10 — Mappa Concettuale Finale

11 — Esercizi Guidati e Svolti

Esercitati con queste applicazioni sulla circonferenza di difficoltà base. Apri i dettagli per verificare.

1. Determina centro e raggio di x² + y² - 4x + 6y - 3 = 0

💡 Svolgimento
Identifichiamo i coefficienti: a = -4, b = 6, c = -3.
• Coordinate del centro: x₀ = -(-4)/2 = 2, y₀ = -6/2 = -3 → C(2, -3).
• Calcolo del raggio: r = √(2² + (-3)² - (-3)) = √(4 + 9 + 3) = √16 = 4.
✅ Risultato: Centro C(2, -3), Raggio r = 4.

2. Trova l'equazione della circonferenza di centro C(-1, 2) e passante per P(2, 6)

💡 Svolgimento
1. Calcoliamo il raggio r come distanza tra C e P: r = √[(2 - (-1))² + (6 - 2)²] = √[3² + 4²] = √(9 + 16) = √25 = 5
2. Usiamo l'equazione con centro e raggio: (x - x₀)² + (y - y₀)² = r²
3. Sostituiamo i valori: (x + 1)² + (y - 2)² = 25
4. Sviluppiamo i quadrati: x² + 2x + 1 + y² - 4y + 4 = 25 → x² + y² + 2x - 4y - 20 = 0
✅ Risultato: x² + y² + 2x - 4y - 20 = 0

3. Calcola la retta tangente alla circonferenza x² + y² = 25 nel punto P(3, 4)

💡 Svolgimento
1. Verifichiamo che P appartiene alla circonferenza: 3² + 4² = 9 + 16 = 25 (Sì).
2. Applichiamo la formula di sdoppiamento per la circonferenza x² + y² - 25 = 0: x₀x + y₀y - 25 = 0
3. Sostituiamo x₀ = 3 e y₀ = 4: 3x + 4y - 25 = 0
✅ Risultato: 3x + 4y - 25 = 0 (in forma esplicita: y = -3/4 x + 25/4).
12 — Verifica Finale (5 Minuti)

Controlla la tua preparazione prima di chiudere il modulo.

Parte 1: Quesiti Teorici

  1. Qual è la condizione algebrica affinché l'equazione x² + y² + ax + by + c = 0 rappresenti una circonferenza reale?
  2. Cosa indica geometricamente l'annullamento del coefficiente c nell'equazione canonica?

Parte 2: Esercizi di Calcolo

  1. Determina le coordinate del centro e il raggio della circonferenza x² + y² + 8x - 10y + 16 = 0.
  2. Scrivi l'equazione della circonferenza avente centro nell'origine O(0,0) e raggio r = 6.
  3. Stabilisci la posizione relativa tra la retta y = 2 e la circonferenza x² + y² = 9.
🔍 Mostra Soluzioni di Controllo

Teoria 1: Il radicando nella formula del raggio deve essere strettamente positivo (o non negativo per una circonferenza degenere): (a/2)² + (b/2)² - c ≥ 0.

Teoria 2: Se c = 0, la circonferenza passa per l'origine degli assi cartesiani O(0,0).

Es.1: a = 8, b = -10, c = 16 → C(-4, 5); r = √((-4)² + 5² - 16) = √(16 + 25 - 16) = √25 = 5.

Es.2: x² + y² = 36 (oppure x² + y² - 36 = 0).

Es.3: Il raggio è r = 3. La distanza della retta parallela all'asse x: y = 2 dal centro (0,0) è d = 2. Poiché d < r (2 < 3), la retta è secante in due punti. Ergo, interseca la circonferenza in due punti.
